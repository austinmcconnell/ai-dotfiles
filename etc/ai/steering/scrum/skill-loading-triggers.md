# Skill Loading Triggers

Triggers common to every agent, and the rule for applying them, live in
`shared/skill-loading-triggers.md`. The rows below are specific to this domain.

| Task                                          | Skill to load first  |
| --------------------------------------------- | -------------------- |
| Deciding which sections any Jira ticket needs | `ticket-writing`     |
| Writing user stories                          | `user-story-writing` |
| Writing bug tickets                           | `bug-ticket-writing` |
| Creating any JIRA ticket/issue/task           | `user-story-writing` |
| Adding to backlog                             | `user-story-writing` |
| SCRUM ceremony questions                      | `scrum-reference`    |
| Sprint context, standup, or planning queries  | `jira-operations`    |
| Transitioning, linking, or searching issues   | `jira-operations`    |
| Validating Jira setup or API connectivity     | `jira-smoke-test`    |
